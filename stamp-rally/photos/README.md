# 写真の置き場所

校内クイズ探検の4択に使う写真を、このフォルダ（`stamp-rally/photos/`）に置きます。
ファイル名は下の表のとおりにしてください。写真が置かれた選択肢だけ、現在の絵（絵文字・線画）から写真に差し替えます。

## 写真の条件
- 形式：`.jpg`（`.png` でも可。その場合は表の拡張子を読み替えます）
- 大きさ：横 400〜800px 程度、1枚 200KB 以下（スマホで軽く動かすため）
- 権利：学校で撮った写真か、利用が許可されている写真だけを使います。
  パブリックドメインや CC のものは、出典とライセンスを `credits.txt` に1行ずつ書いてください。
  例：`s3-kukai.jpg | 空海像 | Wikimedia Commons | パブリックドメイン | URL`
- 人物の写真は、故人の肖像画・古い写真など、権利が切れているものにしてください。
